# Balaji S — .NET Full Stack Developer Portfolio

## Run locally
1. Extract this ZIP file.
2. Open `BalajiPortfolio/index.html` in a browser.

## Add your actual resume PDF
The portfolio includes a **Download Resume** button in the navigation and hero section.

To make the button download your resume:
1. Export your latest resume as a PDF.
2. Name the file exactly `Balaji_S_Resume.pdf`.
3. Copy it into the `assets` folder (the same folder as this README is not correct; use `BalajiPortfolio/assets/`).
4. Keep the folder structure unchanged when uploading/deploying the site.

Expected structure:

```
BalajiPortfolio/
  index.html
  README.md
  assets/
    Balaji_S_Resume.pdf   # add your actual resume here
```

The resume PDF was not included because no PDF was provided in this chat. Do not publish the site until you add and test your current resume.

## Update your details
Open `index.html` in VS Code or another editor. Search for the text you want to update, such as email, phone, LinkedIn, GitHub, experience, and project descriptions.

## Publish
You can host this static website on GitHub Pages, Netlify, or another static web host. Upload the complete `BalajiPortfolio` folder, including `assets`.
